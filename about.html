📋 О проекте

Мои распорядки — это прогрессивное веб-приложение (PWA) для формирования полезных привычек и организации распорядка дня.

Приложение работает в офлайн-режиме, поддерживает установку на домашний экран и синхронизирует данные между устройствами.

🛠️ Технологии

  • Frontend: HTML, CSS, JavaScript (ES6+)
  • PWA: Service Worker, Web App Manifest
  • Backend: Node.js, Express, PostgreSQL
  • Аутентификация: JWT, bcrypt
